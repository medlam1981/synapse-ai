# Synapse AI Agent 🧠⚡

Synapse AI (formerly Medlam-AI) is an advanced, autonomous on-device AI agent designed for Android. It fuses cutting-edge cloud reasoning with deep system-level integration to provide a seamless, secure, and highly intelligent digital assistant right on your mobile device.

📥 **[Download Latest APK](https://github.com/medlam1981/synapse-ai/raw/main/releases/app-debug.apk)**

## 🔥 Key Features

- **Autonomous Agent Engine**: A robust background task engine (`BackgroundTaskEngine`) capable of multi-step reasoning, executing complex workflows independently without user intervention.
- **Deep Android Integration**: Uses advanced Android Accessibility Services to navigate the device, perform gestures, click elements, and interact with applications autonomously.
- **Precision Text Input**: Features a custom `SynapseKeyboardIME` for perfectly accurate, fast, and native-like text input across any app, avoiding the pitfalls of standard accessibility text injection.
- **Advanced Task Scheduling**: Queue commands for the future. View, edit, or manually stop actively running scheduled tasks at any time using the sleek `Active Tasks` dashboard.
- **Intelligent API Key Rotation**: Efficiently manages multiple Gemini API keys in a rotating queue to ensure high availability and bypass rate limits.
- **High-Performance Memory Management**: State-of-the-art memory architecture designed to run on custom ROMs (such as Kali NetHunter) with optimal CPU/Thermal footprints.
- **Professional & Clean UI**: A strictly professional, cyber-aesthetic interface. No floating bubbles or disruptive overlays—just pure, focused productivity.
- **Multilingual Support**: Fully optimized to understand and converse in multiple languages, with a primary focus on professional and precise Arabic.

## 🌟 What Sets Synapse AI Apart?

Synapse AI goes beyond typical chatbots. It is an **Agent** that acts on your behalf:
- **It Acts**: Instead of just telling you how to do something, Synapse AI opens apps and does it for you.
- **It Schedules**: Need a task done every hour or at a specific time? Schedule it, and the background engine will handle it.
- **It Aborts Gracefully**: Full user control. If a background agent is executing a task, you can intervene and cancel the operation instantly with a single tap.

## 🚀 Getting Started

1. **Install**: Clone the repository and build the APK using Android Studio, or download the latest release.
2. **Launch & Permissions**: Open Synapse AI and grant the necessary Accessibility and IME (Input Method) permissions.
3. **Configure**: Enter your Gemini API keys in the settings menu.
4. **Interact**: Command the agent via the terminal or schedule a task to let the autonomous system take over.
