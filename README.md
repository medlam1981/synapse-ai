# Medlam-AI Agent - The Advanced Hybrid Neural Interface 🧠⚡

Medlam-AI is a next-generation, autonomous on-device AI agent designed for Android. It fuses local computational power with cloud-scale reasoning to provide a seamless, secure, and highly intelligent digital ecosystem right on your mobile device.

## 🔥 Key Features

- **Hybrid Intelligence Core**: Leverages the blazing speed of `gemini-2.5-flash` for cloud reasoning while maintaining a local Ollama-compatible bridge (`11434`).
- **Multilingual Voice Command**: Intelligent speech-to-text with universal language support, prominently featuring full compatibility with **Moroccan Darija (ar-MA)**.
- **Silent Execution Mode**: A perfectly clean interface that hides technical logs, thinking processes, and code blocks, showing only final results and a sleek "thinking" status bar.
- **Multimodal & Document Intelligence**: ENDOWED with high-precision screen reading, image analysis, and advanced PDF/Text parsing (Local NotebookLM style) for deep document interaction.
- **Autonomous Device Control**: Navigates the device, performs gestures, and interacts with applications using advanced Android Accessibility Services—no root required.
- **Specialized Agent Hub**: Extensible architecture allowing you to load expert personas from `.md` files in your storage. Toggle experts on/off as needed.
- **Intelligent Quota Management**: Sequential API key rotation with live dashboard tracking (`KEY: 1/5`) and granular control over background tasks (Visual History, Neural Reflexes).
- **Optimized Neumorphic UI/UX**: A state-of-the-art, deeply engraved dashboard featuring compact, elegantly spaced controls and live hardware telemetry.

## 🌟 What Sets Medlam-AI Apart?

Medlam-AI is not just a chatbot; it's a capable agent that acts on your behalf.
- **Smart Response Engine**: It automatically detects your spoken language and replies in kind. Speak in Darija, and it responds in Darija.
- **Expert Personas**: Switch between general assistance and specialized expertise (like System Diagnostics) instantly via the Expert Manager.
- **Visual Archive**: Optional background visual memory that helps the agent remember what you saw on screen earlier.
- **Universal Bridge**: Built-in proxy for third-party app integration.

## 🚀 Getting Started

1. **Install**: Clone the repository and build the APK using Android Studio or Gradle.
2. **Launch**: Open Medlam-AI on your Android device.
3. **Configure**: Enter your Gemini API keys in the system settings.
4. **Experts**: Place your expert `.md` files in `/sdcard/MedlamAI/Agents/` and enable them in Settings.
5. **Interact**: Use the sleek text terminal, hit the microphone to speak naturally, or attach a file to begin your autonomous session.
